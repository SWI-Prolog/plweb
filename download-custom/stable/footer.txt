## SWI-Prolog version 11.0

SWI-Prolog 11.0 is the latest stable release.  It collects the
development series 10.1.x (December 2025 to November 2026).
Highlights:

  - __Memory management__.  Generational stack garbage collection is on
    by default, functors are garbage collected, and stream handles, clause
    references, tables and new atoms can be reclaimed by their own
    thread without a global atom GC.  The new flag `gc_code` also
    reclaims predicates and modules that were created at runtime and
    are no longer referenced, so programs that create predicates or
    modules from data no longer leak memory.
  - __Performance__.  The VM uses tail-calling VMI functions (GCC 15 or
    later), arithmetic has integer fast paths and clause selection is
    inlined for the common cases.  Tabling is much faster and uses less
    memory.
  - __Unicode__.  Unicode 17 support, independent of the locale.
    Display-width-aware column handling in format/2, strict UTF-8
    decoding, and Unicode bracket and quote pairs in the syntax.
  - __Development environment__.  The IDE is now a single window whose
    tools are panes and tabs.  It supports themes (including dark mode),
    the terminal supports command blocks, search and hyperlinks, and
    PceEmacs has an LSP client.  The profiler reports exact wall and CPU
    time and shows a call graph and call tree.
  - __Graphics__.  The SDL3/Cairo based xpce backend introduced with
    10.0 has matured and adds vector paths, gradients, shadows, SVG
    output, animation, sound, video and touch and pen input.
  - __Stability and security__.  About 60 crashes and races are fixed
    in the core.  Servers and libraries are hardened: HTTP size and
    time limits, HttpOnly session cookies, stricter TLS host
    verification, no external entities in SGML/XML by default and pack
    archives are checked against their hash.
  - __Platforms__.  A signed and notarized MacOS installer (`.pkg`)
    and a Windows installer for ARM64.

### Upgrading from 10.0

Most Prolog code runs unchanged.  `.qlf` files and saved states must be
rebuilt and programs that embed Prolog must be relinked against
`libswipl.so.11`.  Foreign code that passes pointers as integers,
programs that store term_hash/2 or variant_sha1/2 results persistently
and HTTP servers that handle large requests may need attention.
